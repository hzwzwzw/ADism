# 发布前检查与验证

本记录对应已发布标签 `v0.7.0-beta.1`，不代表之后的本地未发布修改已完成同等验证。测试使用可恢复 Windows 11 虚拟机与独立实验磁盘，不包含宿主物理磁盘操作。公开材料不包含实验凭据、系统镜像或 Windows 组件二进制文件。

## 已完成的检查

| 范围 | 结果 |
| --- | --- |
| 代码流程审查 | 系统组件维护使用 Windows 组件服务；系统文件维护使用系统目录中的系统文件检查器；镜像释放使用 Windows 映像处理接口。 |
| 部署目标保护 | 系统盘、实际启动盘、非空白目标、非根目录和原始设备形式的输入会被拒绝。已有数据保留检查通过。 |
| 独立目标识别 | 无盘符 NTFS 与 EFI 分区可解析为临时盘符；任务结束后的映射清理通过。 |
| 真实镜像部署 | Windows 11 x64 WIM 第 3 个映像、便携式系统配置及 UEFI 引导文件写入返回成功。 |
| 真实离线组件检查 | 独立实验磁盘上的完整扫描返回成功，健康状态 0，后续清理完成。 |
| 来源和工作进程协议 | 来源传递、预先取消、异常退出、重复结果、不完整结果和无效参数等 16 项模拟协议检查通过。 |
| 自检 | 内存接口、日志分组与计数、输出解析、命令行引用和辅助逻辑自检通过。 |

Windows 原生持续集成构建与自动化测试通过；发布二进制在 Windows 中运行自检和 16 项协议检查均退出成功。独立目标保护及分区处理的 21 项检查通过。实际离线系统文件完整验证返回成功且报告无完整性冲突；部署前后固件启动配置一致，目标 EFI 引导文件与 BCD 存在。

附加的只读 WIM 来源测试成功完成来源登记并进入真实组件维护。测试宿主随后触发生产代码的协作取消链，组件服务返回 `0x800F0821`，最终健康状态未知。工作进程自然退出，只读来源卸载成功，临时映射清理完成。本项仅作为来源传递和取消清理证据，不属于损坏修复成功，也不属于图形界面停止按钮测试；取消后的实验映像必须重新扫描才能确认健康状态。

一次测试宿主因未包含产品已有的 Windows 兼容性声明，使组件服务把宿主版本识别为旧版本并返回初始化错误；补齐与产品相同的声明后，完整扫描通过。该错误没有被当作修复成功，也没有通过更换修复引擎绕过。

## 验证边界

本轮没有重新构造系统损坏来验证在线内容下载和损坏修复，健康映像的扫描成功不代表任意损坏都可恢复。尚未完成真实 Windows PE、全部固件、所有存储控制器、动态跨盘卷、突然断电与强杀恢复的回归。

BIOS 路径使用微软工具并要求有效签名和预先准备好的活动主分区；尚未将所有 BIOS 启动布局作为已验证范围。系统工具自身、损坏介质、错误来源与意外断电仍可能导致维护无法完成。

源码审查与测试用于降低已识别风险，不构成对所有 Windows 版本和硬件环境的无风险保证。
