# 验证记录与支持边界

本记录对应 0.7.1 Beta 1。测试使用可恢复 Windows 11 x64 虚拟机；公开材料不包含实验凭据、系统镜像或 Windows 组件二进制文件。

## 本版修改与检查

| 范围 | 验证内容与结果 |
| --- | --- |
| 产品自检 | 参数引用、SFC 输出分类、进度解析、PE 内存设备名称边界及辅助逻辑检查通过。 |
| SFC 程序选择 | Windows 原生只读检查 5 项通过，包含运行环境优先、缺失时验证目标候选、在线不回退、两侧缺失失败、其他微软程序身份拒绝。 |
| 工作进程协议 | 20 项通过，包含 WIM 工作分区参数往返、异常退出、重复／不完整结果和矛盾／无效参数拒绝。 |
| 工作分区与清理 | 原生实验检查 7 项通过，包含非法路径拒绝、指定分区不受 TEMP 影响、具体失败步骤保留、独占空目录清理和预先取消。 |
| 图形界面 | Wine 中 32 项检查通过，包含移除 SFC 引导分区输入、WIM 工作分区默认值、条件显隐及选择保留。 |
| Windows 构建与默认测试 | 对应提交的原生构建和 CTest 记录见 [Windows build](https://github.com/hzwzwzw/ADism/actions/workflows/build.yml)。 |

SFC 程序选择通过不存在的模拟运行环境路径进入回退，读取正常 Windows 的 SFC 文件、映像版本资源及微软目录签名；没有移动或删除系统文件，也没有启动 SFC 修复。工作分区实验使用不存在的 WIM，只创建并清理本次 GUID 空目录，不挂载镜像、不运行 CBS。默认自动化测试不会执行真实系统维护；需要管理员权限的工作目录实验不是默认 CTest 的一部分。

离线 WIM 修复来源默认在待修复 Windows 分区建立工作目录，手动选择时使用指定的本地可写 NTFS 分区。挂载与 Scratch 共用该分区；失败报告阶段、目录和 HRESULT，清理仍只处理本次拥有的挂载及空目录。

## 已有实际维护验证

前一版本已完成独立目标 WIM 第 3 个映像释放、便携式系统配置、UEFI 引导文件写入、完整离线组件扫描和系统文件验证等实际检查。具体记录见 [0.7.0 验证说明](validation-0.7.0.md)。这些结果属于当时的构建与环境，本轮没有重新执行全部实际维护，也不能代替本版 PE 路径验证。

## 尚未验证的范围

本轮没有在真实 Windows PE 中完成 SFC 回退后的实际扫描／修复，没有验证各种 PE 与目标系统版本的依赖兼容性，也没有完整回归离线目标自身 Catalog 目录的查找。离线 SFC 现在由目标系统分区生成 `/offbootdir`，不要求选择 EFI 分区；该默认值尚未经过各类实际启动布局的全面验证。

本轮没有重跑真实 PE 的 WIM 挂载或完整 RestoreHealth。程序选择、工作目录检查及健康样本成功，均不等于损坏修复成功。微软签名或信任链无法确认时会明确失败，不会放宽验证或伪报成功。

真实 PE、全部 BIOS／固件、复杂存储控制器、动态跨盘卷、突然断电与强杀恢复仍未完成完整回归。组件服务使用 Windows 内部接口，未来维护堆栈变化可能影响兼容性。

源码审查与测试用于降低已识别风险，不构成对所有 Windows 版本和硬件环境的无风险保证。
