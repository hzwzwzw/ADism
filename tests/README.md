# 验证程序

默认 CTest 运行产品 `--self-test` 和进程间协议测试。它们使用内存中的模拟接口和独立测试子进程，不调用真实 CBS/SFC 维护，不释放镜像或写入引导。协议测试覆盖来源往返、预先取消、异常退出、重复/不完整结果，以及缺少或矛盾的操作参数。

可选的交互界面和分区访问程序使用 `-DADISM_BUILD_INTERACTIVE_TESTS=ON` 构建，只应在可恢复的 Windows 实验虚拟机运行。交互程序包含非空白实验卷的临时盘符验证，要求事先准备无盘符、卷标 ADISM06_NTFS 的独立测试卷；没有该卷会报告失败。程序本身不会格式化或创建分区。

`ADismPartitionProbe` 无参数时只枚举。显式传入完整卷 GUID 与匹配卷标时，会要求所选卷无盘符，再验证身份不匹配拒绝、临时挂载、重复解析、创建/删除自身探针文件及映射清理。该模式会写入所选卷，禁止在主力系统或含重要数据的卷上运行。
